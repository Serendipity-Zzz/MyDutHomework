# 数字示波器 II：触发系统实验

本次作业选择的**学号末位为 1**，指定释抑时间：

H = (1 + 1) × 0.1 ms = **0.200 ms**。

## 提交文件

直接提交 `实验报告_学号末位1.html` 即可。截图、数据表、理论比较和分析结论均已内嵌；不需要连同脚本或其他文件一起提交。

本目录仅保留报告、README、生成脚本和双击入口，不含检查记录、校验文件、压缩包或外置图片目录。

## 为其他学号生成

1. 双击 `双击生成.cmd`。
2. 输入学号末位 0～9，回车等待完成；直接回车默认使用 1。
3. 获得 `实验报告_学号末位N.html`，只提交对应的这一个 HTML。

生成相同末位时会更新该末位的报告；其他末位的报告保留。生成失败时不替换已有报告。

命令行也可以运行：

```powershell
python "个性化生成.py" --digit 5
python "个性化生成.py" --digit 5 --output "我的作业.html"
```

## 运行环境

Python 3.10 或以上、NumPy、Playwright，及本机 Chrome 或 Edge。
首次缺少依赖时运行：

```powershell
python -m pip install numpy playwright
```

脚本自动寻找 Chrome / Edge；无本机浏览器时可运行 `python -m playwright install chromium`，也可通过 `--browser "浏览器exe完整路径"` 指定。
脚本与整个文件夹可移动；任意工作目录启动均可，默认输出到脚本所在目录。`--output` 的相对路径同样以脚本目录为基准。

## 参数如何同步

- 对末位 N，使用 H = (N + 1) × 0.1 ms。
- 重新计算 200 万点复合信号、三种触发的接受/屏蔽序列，再用浏览器重新截图，更新表格、叠加波形与结论。
- 使用同一输入参数和固定随机种子，因此方波频率、毛刺宽度等输入测量值可能不变；变化的是释抑区间和触发结果。这符合固定输入、改变触发设置的实验方法。
- 末位 0 对应 100 μs，可能在同一猝发内重复触发；末位 9 对应 1 ms，可能因采样时钟偏差产生触发相位滑移。脚本如实呈现，不将所有末位都写成“稳定首脉冲锁定”。
- 生成过程中的观察页和截图保存在系统临时目录，完成后清理；生成 HTML 不依赖相对图片路径或本机绝对路径，可离线单独查看。

本实验为数值仿真，未连接实物示波器。
