# 迈克耳孙干涉实验作业

## 直接查看

双击根目录 `index.html`，可离线阅读两个实验的原理、数据、计算、图表、结论并播放视频；无需安装Python。打印按钮可调用浏览器打印。请保持文件夹结构完整。

## 配置与启动交互程序

需要Python 3.10+（推荐3.11）、FFmpeg（含ffmpeg与ffprobe）。先安装依赖，在本目录打开PowerShell运行：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r .\应用
equirements.txt
ffmpeg -version
ffprobe -version
```

FFmpeg的bin目录须加入PATH；修改后重新打开终端。无需GPU、语音模型、API密钥或网络服务。Python依赖安装需要联网。

双击 `启动实验台.cmd`。启动器优先使用本目录`.venv`，检查环境后打开本地网页；默认端口8765，若其他目录或旧版服务占用，会选择后续可用端口。请保留启动窗口，按Ctrl+C停止。启动失败的窗口会保留提示，日志在运行时生成的`work/启动日志.txt`。

也可从终端运行（跨平台需自行激活相应Python环境）：

```powershell
.\.venv\Scripts\python.exe launcher.py
# 指定端口，不自动打开浏览器
.\.venv\Scripts\python.exe launcher.py --port 8770 --no-open
```

## 怎么使用

1. 点击“载入作业数据”，恢复波长五段、空气三次记录与关联视频；“查看作业报告”可打开整理后的报告。
2. 切换“激光波长测量”或“空气折射率测量”；点击记录起点可定位对应视频。兼容预览随作业提供，计数仍读取原始视频。
3. 新素材可通过路径或文件导入。设置分析起止时间、框选ROI，运行“分析条纹与声音”。高级参数可选空间相位法或亮度峰值法。
4. 声音检测只给候选起点，不识别报数。波长标记填写累计圈次（如0秒第0圈、8秒第1圈），按圈次差生成记录；也可手动输入时间、转动量与条纹数。空气实验填写实际压差，默认35 kPa。
5. 核查记录后勾选采用。可修正条纹数并填写说明；原自动计数会保留。点击“保存项目”“导出CSV”或“导出HTML报告”，文件写入`报告与导出`。

## 目录与架构

```text
index.html             可双击查看的完整作业报告
README.md              本说明
启动实验台.cmd          Windows启动入口
launcher.py            Python环境检查与启动日志
应用/
  server.py            本机HTTP服务、视频导入、任务与导出
  analyzer.py          FFmpeg解码、亮度计数、音频起点与兼容预览
  spatial.py           空间载波相位跟踪与质量提示
  requirements.txt     NumPy、SciPy依赖
  static/              HTML/CSS界面、Canvas图表与JavaScript计算
素材/                  四段原视频
  预览/                H.264兼容预览
报告与导出/             可恢复项目与两类CSV；后续导出也写入这里
```

浏览器负责交互、单位换算、拟合与报告；
- FFmpeg / FFprobe：读取视频信息、解码视频帧、提取音频、生成兼容预览。
- NumPy / SciPy：空间傅里叶分析、相位展开、滤波、条纹计数和声音起点检测。
- JavaScript：实验公式计算、最小二乘拟合、图表与报告导出。
分析服务只监听127.0.0.1。项目内素材使用相对路径，整个目录复制后仍可恢复。运行时会自动建立`数据`和`work`保存新结果与日志；交付目录未附带开发缓存、转写模型、测试截图或历史排查文件。

## 结果

位移固定按未核验的10 μm/圈对标假设计算；5 μm/圈仅用于报告中的比例误差对照，未改默认档位。波长五圈总量法约1252.800 nm；最小二乘法约1272.430 nm，方法不同所以数值略异。**实验结果很大程度会受到视频录制质量的影响，由于未采用opencv等图像识别技术，结果误差偏移量会较大，本次实验的结果受到我拍摄视频质量的问题，也有很大的误差。**5 μm/圈对照总量法约626.400 nm，不能据此认定真实器材档位。空气实验采用讲义参考λ=632.8 nm、L=60 mm、p=101325 Pa；三次保留记录，第1次待复核不纳入均值。自动计数是候选，重复性不等于绝对准确度。程序中的“模拟演示”会明确标记，不属于本作业实测数据。
