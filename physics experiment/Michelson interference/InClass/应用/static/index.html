THE EXPERIMENT

从光程差到可测量的位移

反射镜移动 Δd，往返光程改变 2Δd。固定位置从明到暗再回到明，是一个完整的条纹周期。

波长测量 λ = 2Δd / N空气折射率 n = 1 + λpΔk / (2LΔp)

空气实验使用有限压差法。Δp 是压差，p 是环境绝对气压；压力表回零通常代表与大气等压。
